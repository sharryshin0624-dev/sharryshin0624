우리 교실 설정

보내주신 시간표가 요일별로 적용되어 있습니다. 수업 시각은 학교 일정에 맞게 조정해 주세요.

시작, 종료 시각 순서로 입력하세요. 점심시간은 앞 수업 종료와 다음 수업 시작 사이의 빈 시간으로 두면 됩니다. 수업이 없는 요일은 모든 교시를 삭제하세요.

사용 방법과 저장 안내

HTML 파일을 내려받아 웹페이지형 라이브 월페이퍼로 불러오세요. 입력하려면 월페이퍼 프로그램의 마우스, 키보드 상호작용을 켜야 합니다. 날짜와 시각은 한국 시간 기준입니다.

시간표와 준비물은 현재 브라우저 또는 월페이퍼의 저장 공간에 보관됩니다. 다른 프로그램이나 기기로 옮길 때는 아래 백업을 사용하세요.

마이크는 켜기 버튼을 눌러 허용한 뒤 사용합니다. 소음 수치는 보정되지 않은 상대값(0~100)이며, 0~39는 초록색 안정, 40~49는 노란색 보통, 50 이상은 빨간색 큰소리 / 시끄러워요를 표시합니다. 녹음하거나 전송하지 않습니다. 마이크를 지원하지 않는 월페이퍼에서는 일반 브라우저로 열어 주세요.

채팅은 인터넷과 기존 Apps Script 배포가 필요합니다. 실제 카카오톡 계정과 연동되지 않습니다. Code.gs는 구글 서버에서 실행하므로 HTML 안에서 직접 실행되지 않습니다.
